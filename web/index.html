FOR YOUR DESKTOP

Install Baton.

One command adds the hand to your Omarchy bar. Left-click waves. That’s the whole manual.

omarchy plugin add https://github.com/decadentsavant/baton.git --enable

Prefer the launcher?

Press Super + Space, search for Add Plugin, and paste https://github.com/decadentsavant/baton
